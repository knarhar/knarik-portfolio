# 🌟 Knarik Harutyunyan - Portfolio Website

A modern, responsive portfolio website built with React and Tailwind CSS, featuring smooth animations, dark theme, and a beautiful blue/violet color palette.

## ✨ Features

- 🎨 **Modern Dark Theme** with animated gradient backgrounds
- 🎭 **Smooth Animations** - Fade-in on scroll, hover effects, and floating elements
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- 🎯 **Single Page Application** with smooth scrolling navigation
- 🌈 **Beautiful Color Palette** - Blue and violet accent colors
- ⚡ **Performance Optimized** - Fast loading and smooth interactions
- 🔗 **Social Media Integration** - Links to GitHub, LinkedIn, and email

## 🚀 Sections

- **Hero** - Eye-catching introduction with animated background
- **About** - Background, approach, and work experience
- **Skills** - Technologies organized by category (Frontend, Backend, Tools, AI)
- **Projects** - Featured projects with descriptions and tech stack
- **Contact** - Get in touch with social links and contact information

## 🛠️ Tech Stack

- **React** - JavaScript library for building user interfaces
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library
- **GitHub Pages** - Free hosting for static sites
